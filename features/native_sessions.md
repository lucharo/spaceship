# Native sessions

Spaceship's main Threads list is the provider-native catalogue, not a second Spaceship history beside it. The Codex provider plugin lists active app-server threads, opens and continues the selected native ID, and offers pins, calendar-safe grouping, search, archive, and right-click actions. Archive goes straight to the provider and does not create a local thread. An opened projection keeps enough native identity to unarchive through Codex after workspace pruning, and local state changes only after provider acceptance. Transcript bodies are read only after the user opens one session, while import or migration remains explicit.
